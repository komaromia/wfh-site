# WFH website

This directory is the source of the public WFH website. It is deployed from a **separate public repo**, `komaromia/wfh-site` (same setup as `kjournal-site` and `kdocu-site`), so this app repo can stay private.

- Home: https://komaromia.github.io/wfh-site/
- Privacy policy: https://komaromia.github.io/wfh-site/privacy.html
- Support: https://komaromia.github.io/wfh-site/support.html
- Terms: https://komaromia.github.io/wfh-site/terms.html

The app uses these through `AppLinks`. App Store Connect needs the Privacy Policy and Support URLs.

Publishing: edit files here, then run `tools/publish-site.sh` (mirrors `site/` to the root of the site repo, commits, pushes). Pages serves `main` at `/`; `.nojekyll` keeps files served as-is. No GitHub Actions workflow.

Fonts: Barlow and Barlow Condensed (SIL OFL, see `fonts/OFL-Barlow.txt`) are self-hosted so the pages load nothing from third parties. Colours follow `docs/DESIGN.md` §3. `icon.png` is the app icon, generated by `tools/make-icon.swift`.

`builder.html` (with `workout-builder.js`, `catalog.js`) builds workouts in the browser and shares them as links; `open.html` (with `open-workout.js`) is the landing page for a shared link. They are generated from the app repo's `site/` folder.
